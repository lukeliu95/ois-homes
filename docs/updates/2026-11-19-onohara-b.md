# 2026年11月19日，小野原西B栋上线待核区

按用户指示，公开小野原西3丁目B栋。原广告月租28万日元、100.4平方米、木造两层。广告建月为2026年11月，预计12月上旬入住，实际竣工和空室待确认。停车概要明确1台免费，广告称可停2台，第2台条件待核。[原中介](https://www.able.co.jp/kodate/detail/Detail.do?bk=000000189756760001&prefkey=osaka&w=27220037&cf=0&ct=0&sf=0&b=06&n=B) · [SUUMO](https://suumo.jp/chintai/bc_100527787208/)

已上架14张实拍和1张完整两层户型图。到校路线页提供广告地图点的参考骑行，11月19日显示约2分钟、300米。广告只公开到丁目，完整门牌仍待核。站内20分钟筛选使用已核门牌的通学证据，小野原西B栋保留待核状态。
